# From cyst to target and back

Repository with the scripts used for the paper *"From Phenotypic Screening to Target and Compound Prioritization for Autosomal Dominant Polycystic Kidney Disease"*

## Prerequisites

This repository uses [Git LFS](https://git-lfs.github.com/) to store large data files. Make sure Git LFS is installed before cloning:

```shell
git lfs install
git clone <repo-url>
git lfs pull
```

> **Note:** Some data (e.g., the Papyrus subset) can also be regenerated by running the notebooks in order, but pre-computed files are included for convenience.

## Installation

Create the conda/micromamba environment:

```shell
micromamba env create -f environment.yml
micromamba activate cystToTarget
```

Then install all pinned dependencies with **one** of the following options:

### GPU (CUDA 12.4)

```shell
python -m pip install -r requirements-gpu.txt
python -m pip install -r requirements.txt
python -m pip install --no-deps "mood @ git+https://github.com/valence-labs/mood-experiments.git"
python -m pip install -e .
```

### CPU only

```shell
python -m pip install -r requirements-cpu.txt
python -m pip install -r requirements.txt
python -m pip install --no-deps "mood @ git+https://github.com/valence-labs/mood-experiments.git"
python -m pip install -e .
```

> **Note:** The `mood` package is installed with `--no-deps` because it declares an overly restrictive `numpy<1.24` pin that conflicts with other dependencies. It works correctly with newer numpy versions at runtime.

> **Note:** For other CUDA versions, adjust the index URL in `requirements-gpu.txt` following
> [PyTorch's install guide](https://pytorch.org/get-started/locally/).

# Structure

## Data

All data used and generated in our paper are stored under the `data/` directory.

For information on the available files, please refer to the [data/README.md](data/README.md) file.

## Execution order

The numbered directories correspond to the workflow described in the paper and should be executed sequentially:

1. **01_ADPKD_ScreeningProcess** — Hit identification from phenotypic screening data
2. **02_TargetID_and_Prioritization** — Target identification via Papyrus and prioritization
3. **03_Target_Validation** — Analysis of the target validation screening experiment
4. **04_Virtual_Screening** — QSAR model training, virtual screening, and compound exploration phenotypic results
5. **05_A1R_Screening** — A1AR radioligand displacement assay results

## 01_ADPKD_ScreeningProcess

This directory contains the scripts used to process the ADPKD screening data coming from (Booij et al. 2017; Booij et al. 2020). The pre-computed outputs are included in the repository under `data/adpkd_screening/`. To re-generate the outputs needed for the following steps, run:

```shell
cd 01_ADPKD_ScreeningProcess
python screening_process.py
python hit_identification.py
```

## 02_TargetID_and_Prioritization

This directory contains the notebook used to identify the targets of the ADPKD-screened compounds, processed according to [01_ADPKD_ScreeningProcess](#01_adpkd_screeningprocess). A prioritization scheme is also performed for target selection.

### 1. papyrus_data_linker.ipynb

This notebooks performs the target identification and prioritization of the identified targets according to the ADPKD bioactivity. Three different plots are generated:

1. [A Venn diagram](figures/ADPKD-Bioactivity_and_TargetSpace.svg) showing the overlap between targets and the four bioactivity classes (cyst-swelling enhancers, reducers, inactives and antineoplastic);
2. [Bar plot with N(compounds) per bioactivity class](figures/ADPKD-Compound_Bioactivity_Counts-Has_Papyrus_Data.svg);
3. [Bar plot with the prioritized targets](figures/ADPKD-Prioritized_Target_Set-prioritized.svg). On the top part, the number of actives is shown ($N_{active}$), and on the bottom part, the Cyst Swelling (CS) bioactivity ratio: $CS_{ratio} = N_{active}/(N_{total})$, where $N_{total}$ is the total number of ADPKD-screened compounds active for that target on the given threshold (default: $pchembl\_value < 6.5$)

To reproduce the results and analysis, follow the steps in the notebook [papyrus_data_linker.ipynb](02_TargetID_and_Prioritization/papyrus_data_linker.ipynb).

### 2. gene_expression/gene_plotting.ipynb

This notebook visualizes the gene expression levels (CPM and raw counts) for the prioritized targets in the mIMCD3 cell line, used to confirm target expression in the screened cell model.

## 03_Target_Validation

This directory contains the notebook used to visualize the results from the ADPKD cystic spheroid target validation experiment. The input data for this notebook is the `data/target_validation/ADPKD-TargetValidationScreen_Batch3791_and_Batch3753.csv` file. The generated figures are the following:

1. Boxplots with Mann-Whitney U test results for the different distributions of the treatment and double treatment groups along the three concentration points (0.001, 0.1, and 1 µM).
2. Point plots with the 95% confidence intervals of the treatment groups along the three concentration points (0.001, 0.1, and 1 µM).

## 04_Virtual_Screening

This directory contains the QSAR model training, virtual screening, and compound exploration analysis. See the [04_Virtual_Screening/README.md](04_Virtual_Screening/README.md) for detailed results and statistical tests. The notebooks are:

1. [modelTrain-adora1_nr3c2.ipynb](04_Virtual_Screening/modelTrain-adora1_nr3c2.ipynb) — Training and evaluation of XGBoost QSAR models for A1AR (Ki) and MR (Ki/IC50)
2. [virtualScreening.ipynb](04_Virtual_Screening/virtualScreening.ipynb) — Virtual screening of SmallWorld analogues using the trained models
3. [ADPKD-ExplorationScreening-analysis.ipynb](04_Virtual_Screening/ADPKD-ExplorationScreening-analysis.ipynb) — Analysis of the phenotypic screening results for the selected compounds

## 05_A1R_Screening

A1AR radioligand displacement assay results for the QSAR-selected compounds. See the [05_A1R_Screening/README.md](05_A1R_Screening/README.md) for the predicted vs. experimental pKi values.

## figures/mol_structures

The [render_drawings.ipynb](figures/mol_structures/render_drawings.ipynb) notebook generates SVG molecule structure drawings for the compounds used in the target validation and virtual screening experiments.
